# unix-system-programming-uts

> Assignments, exercises, and summaries from the UNIX Systems Programming course at the University of Technology Sydney, covering shell scripting, C system calls, and UNIX process management.

## ✨ TL;DR
```bash
gcc -o program assignment/program.c && ./program
```

## 🚀 Features
- **UNIX system calls:** Implementations of fork, exec, pipes, signals, and file I/O in C.
- **Shell scripting:** Bash scripts for system automation and process management.
- **Summaries:** Concise course summaries in `Summaries/`.

## 🎓 Academic Context
This project was created as part of a university course.
- **Course:** UNIX Systems Programming (32547)
- **Institution:** University of Technology Sydney (UTS)
- **Semester:** Spring Semester 2024 (exchange semester)

---

## 🛠️ Installation

### Prerequisites
- GCC (or clang)
- UNIX/Linux environment (or WSL on Windows)

### Steps
1. Clone the repository:
```bash
git clone https://github.com/HuberNicolas/unix-system-programming-uts
cd unix-system-programming-uts
```

---

## 💻 Usage

```bash
# Compile and run a C program
gcc -o output assignment/program.c && ./output

# Run a shell script
bash exercises/script.sh
```
